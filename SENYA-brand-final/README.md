# SENYA brand assets

Clean SVG masters reconstructed from the approved palm-frame identity; raster PNG exports are rendered from the same paths, so all variants share geometry. The custom wordmark is refined rather than a pixel-exact trace. No font dependency.

- Primary logo: charcoal wordmark, blue Y and mark; light backgrounds.
- Reversed logo: white wordmark, blue Y and mark; dark backgrounds.
- Monochrome: single charcoal color.
- Brand mark: transparent, blue.
- App icon: full square, offwhite background; launcher applies mask.
- Adaptive foreground: transparent 108x108 source with central safe-area artwork; pair with #F6F7F9 Android background.
- PNGs: logos 2064px wide; marks and app icon 1024px; web icon sizes 16–512px.

Colors: blue #8BB8E8, ink #202630, background #F6F7F9. Prefer SVG in the web UI. Keep proportions; do not stretch, recolor, add effects, or redraw the mark in each screen. Keep at least one finger-width of clear space.

Generated image drafts had alpha fringe artifacts; they are excluded from this final folder. These delivered PNGs come from deterministic SVG rendering, not imagegen cutouts.
